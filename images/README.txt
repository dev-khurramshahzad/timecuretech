Put your own photos in this folder using these exact names (JPG):

  hero-bg.jpg     Home banner background   (1920x1080 or larger)
  about.jpg       About section photo      (1000x800)
  services-1.jpg  Network design card      (800x400)
  services-2.jpg  Router and switch card   (800x400)

If a photo is missing, illustration.svg shows instead, so the page never looks empty.
Also in this folder: favicon.svg (browser tab icon).
